# Contributing

Thanks for helping. A few rules keep this project safe to share:

1. **No real data.** Don't put real chat messages, names, emails, company names or ticket keys in issues, PRs, examples or tests. Use made-up ones (Alex, Priya, Acme, PAY-123).
2. **Drafts only.** Pull requests that make the agent send, post or edit anything on the user's behalf without an explicit click will not be merged.
3. **Keep skills short.** Put the core steps in `SKILL.md` and the detail in `references/`.
4. **Say what you tested.** Name the chat tool and tracker you ran it on.

To try your changes locally in Claude Code:

```
/plugin marketplace add ./path/to/your/clone
/plugin install reply-agent@reply-agent
```
